# POST-IMPLEMENTATION ENTERPRISE INTEGRATION & PRODUCTION AUDIT

Bertindaklah sebagai **Principal Enterprise Software Auditor, Chief Software Architect, Principal Security Engineer, QA Lead, DevOps Architect, SaaS Platform Reviewer, dan Production Readiness Assessor**.

## ATURAN WAJIB

* JANGAN mengimplementasikan fitur baru.
* JANGAN melakukan refactor.
* JANGAN membuat migration.
* JANGAN membuat commit.
* JANGAN mengubah source code.
* JANGAN memperbaiki bug.
* JANGAN membuat TODO implementasi.

Tugas Anda hanya **MELAKUKAN AUDIT MENYELURUH** terhadap hasil implementasi seluruh P0 setelah merge.

Semua kesimpulan harus berdasarkan **source code aktual**, hasil build, hasil test, dan perilaku sistem yang benar-benar ada.

# BAGIAN 1 — MERGE INTEGRATION AUDIT

Audit hasil merge.

Cari:

* conflict yang terselesaikan tetapi salah
* duplicate implementation
* duplicate middleware
* duplicate repository
* duplicate context
* duplicate tenant resolution
* duplicate audit hook
* duplicate quotation path
* duplicate event pipeline

Pastikan hanya ada SATU implementasi canonical.

---

# BAGIAN 2 — TENANT ISOLATION AUDIT

Pastikan:

* seluruh query tenant-owned menggunakan tenant scope
* tidak ada query yang lolos tanpa tenant
* worker membawa tenant
* scheduler membawa tenant
* export membawa tenant
* SSE membawa tenant
* AI workflow membawa tenant
* repository selalu memakai RequestContext

Lakukan audit seluruh call path.

---

# BAGIAN 3 — REQUEST CONTEXT AUDIT

Pastikan hanya ada SATU RequestContext canonical.

Cari:

* context lain
* helper lain
* adapter yang tidak lagi dipakai
* legacy context

Pastikan tidak ada fragmentasi.
