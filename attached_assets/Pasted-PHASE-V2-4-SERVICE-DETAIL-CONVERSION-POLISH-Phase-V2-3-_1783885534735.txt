==================================================
1. SERVICE HERO
==================================================

Pertahankan informasi utama, tetapi perbaiki hierarchy.

Hero harus menampilkan dengan jelas:

- breadcrumb
- category
- service name
- concise value proposition
- delivery estimate
- human review availability
- commercial usage status
- package starting price
- rating hanya jika benar-benar tersedia
- project count hanya jika benar-benar tersedia

Tambahkan trust pills seperti:

- Human Reviewed
- Commercial Ready
- Secure Project
- Transparent Pricing

Jangan menampilkan badge yang tidak sesuai data aktual.

Tambahkan CTA utama:

- Choose Package

CTA sekunder:

- Preview Sample

CTA Choose Package harus scroll halus ke package selector.

CTA Preview Sample harus scroll ke portfolio atau AI preview.

==================================================
2. IN-PAGE NAVIGATION
==================================================

Audit navigation section yang sudah ada.

Buat sticky in-page navigation yang memuat:

- Overview
- AI Workforce
- Deliverables
- Packages
- Portfolio
- Reviews
- FAQ

Persyaratan:

- active section indicator berdasarkan scroll
- smooth scroll
- keyboard accessible
- tidak menutup konten
- mobile horizontal scroll
- respects reduced motion

==================================================
3. WHAT YOU WILL RECEIVE
==================================================

Buat section deliverables yang sangat jelas.

Tampilkan hasil konkret yang akan diterima customer.

Contoh struktur:

- Primary deliverables
- Editable files
- Strategy documentation
- Output formats
- Number of concepts
- Included revisions
- Commercial usage
- Human review

Gunakan data existing dari service detail/package.

Jangan hardcode deliverables generik bila data dinamis tersedia.

Tampilkan sebagai card atau checklist premium dengan icon yang relevan.

Tambahkan section:

“Not Included”

hanya jika datanya tersedia atau dapat diturunkan secara aman dari package rules.

==================================================
4. PACKAGE SELECTOR
==================================================

Refine package cards agar customer dapat membandingkan dengan cepat.

Setiap package harus menampilkan:

- package name
- price
- short description
- delivery time
- included revisions
- human review
- deliverable count
- output formats
- recommended state bila memang ada dari data/configuration
- selected state yang jelas

Buat hierarchy:

- selected package paling jelas
- recommended package menonjol secara elegan
- package lain tetap mudah dibandingkan

Tambahkan package comparison toggle atau comparison row jika struktur data mendukung.

Jangan membuat data perbandingan palsu.

==================================================
5. QUOTE CALCULATOR
==================================================

Pertahankan mutation quote existing.

Perbaiki experience:

- harga diperbarui dengan transisi halus
- tampilkan loading calculation state
- tampilkan error state yang jelas
- jangan menghapus harga lama sebelum hasil baru tersedia
- hindari layout shift
- disable CTA saat quote belum valid
- tampilkan breakdown lengkap
- base price
- quantity
- delivery adjustment
- revision adjustment
- add-ons
- discount
- tax
- final total

Tambahkan microcopy:

- No hidden fees
- Final commercial verification before production
- Price may depend on submitted brief

Hanya tampilkan pernyataan yang benar terhadap business flow existing.

==================================================
6. STICKY QUOTE SUMMARY
==================================================

Desktop:

Buat quote summary sticky di sisi kanan bila layout memungkinkan.

Isi:

- service name
- selected package
- quantity
- delivery
- revisions
- add-ons
- subtotal
- tax
- total
- estimated completion
- CTA

Mobile:

Gunakan sticky bottom bar yang ringkas:

- selected package
- total
- Continue button

Saat dibuka, gunakan bottom sheet untuk rincian quote.

Pastikan sticky elements tidak menutup footer, form, atau tombol lain.

7. CUSTOMIZATION & ADD-ONS
==================================================

Refine delivery speed, quantity, revisions, dan add-ons.

- segmented controls
- steppers
- check cards
- helper text
- additional price

- disabled state

Tambahkan tooltip atau explanation pada pilihan yang berpotensi membingungkan.

Jangan mengubah formula harga.

==================================================
11. FAQ
==================================================

Refine FAQ menjadi accordion yang mudah dipindai.

Pastikan:

- keyboard accessible
- aria-expanded
- animated height tanpa layout glitch
- hanya satu atau banyak accordion terbuka sesuai existing behavior
- deep linking tidak diperlukan kecuali sudah tersedia

Tambahkan FAQ penting bila data/API/config existing mendukung:

- Apa yang perlu disiapkan?
- Apakah tersedia revisi?
- Apakah hasil dapat digunakan secara komersial?
- Bagaimana human review bekerja?
- Apa yang terjadi setelah request dikirim?

Jangan membuat jawaban yang bertentangan dengan business flow.

15. PERFORMANCE
==================================================

Periksa:

- lazy image
- dynamic import bila layak
- portfolio image optimization
- unnecessary rerender
- memoization hanya jika berguna
- Framer Motion overhead
- IntersectionObserver cleanup
- event listener cleanup

==================================================

- layanan yang dipilih
