3. PERBAIKI PARSER LEGACY

Perbarui parser agar memiliki hasil eksplisit:

type ParsedChoice = {
  selected: string[];
  custom: string;
  unmatched: string[];
  source: "structured" | "legacy" | "empty";
};

Atau bentuk ekuivalen yang sesuai codebase.

Aturan parsing
Structured value

Contoh:

Meningkatkan penjualan; Meningkatkan brand awareness; Lainnya: Ekspansi regional

Hasil:

selected: [
  "increase-sales",
  "brand-awareness",
  "other"
]

custom: "Ekspansi regional"
source: "structured"
Pure legacy value

Contoh:

Membuat perusahaan lebih dipercaya oleh importir China

Hasil:

selected: ["other"]
custom: "Membuat perusahaan lebih dipercaya oleh importir China"
source: "legacy"
Mixed legacy value

Contoh:

B2B; Distributor; Perusahaan tambang

Jika dua nilai cocok dan satu tidak cocok:

selected: ["b2b", "distributor", "other"]
custom: "Perusahaan tambang"
unmatched: ["Perusahaan tambang"]

Jangan membuang unmatched value.

5. JANGAN AUTOSAVE HANYA KARENA PARSING

Saat halaman memuat draft legacy:

Parsing untuk tampilan tidak boleh langsung menulis ulang data.
Jangan memicu autosave hanya karena normalisasi internal.
Autosave hanya berjalan setelah user benar-benar mengubah jawaban.
Hindari request save pada initial hydration.
Hindari loop:
parse → state update → serialize → autosave → refetch → parse.

Gunakan hydration guard yang sesuai dengan arsitektur existing.

Contoh konsep:

isHydratingRef
hasUserEditedRef

Gunakan implementasi yang paling sesuai; jangan menyalin contoh secara buta.

17. ACCEPTANCE CRITERIA

Phase 2.1 selesai hanya jika:

Semua legacy free-text terlihat di form.

Mixed known/unknown values tidak kehilangan unmatched text.
Parse–serialize round-trip tidak kehilangan informasi.
Initial hydration tidak memicu autosave.
User edit memicu autosave.
Semua service config telah diverifikasi.
Unknown service memakai default config.
Review menampilkan seluruh data.
Edit dari review kembali ke step tepat.
Back/Next tidak menghapus data.
Refresh memulihkan draft.
Submit payload valid.
Tidak ada duplicate save.
Mobile 375px tidak overflow.
Typecheck, tests, dan build lulus.
Ada bukti visual verification pada halaman brief.
