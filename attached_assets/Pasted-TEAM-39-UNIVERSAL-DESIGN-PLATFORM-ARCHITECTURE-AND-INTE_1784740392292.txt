==================================================
ATURAN INTEGRASI
==================================================

1. Fetch semua remote branch.
2. Jangan merge ke main.
3. Jangan force push.
4. Buat backup branch sebelum batch integrasi.
5. Audit commit dan diff setiap branch.
6. Jangan cherry-pick file individual tanpa mencatat alasan.
7. Prefer merge commit per team untuk traceability.
8. Resolve conflict berdasarkan canonical architecture, bukan sekadar membuat
   build hijau.
9. Jangan menghapus test untuk melewati failure.
10. Jangan mengubah expected output agar test palsu lolos.
11. Jangan menandai failure sebagai pre-existing tanpa baseline proof.
