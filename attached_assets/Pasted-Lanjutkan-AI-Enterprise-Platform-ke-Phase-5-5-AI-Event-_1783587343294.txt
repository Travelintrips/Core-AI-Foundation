* Phase 5 AI Job Engine selesai

Tujuan Phase 5.5:
Membuat AI Event Bus agar seluruh modul AI dapat berkomunikasi secara event-driven, bukan saling memanggil langsung.

PENTING:
Jangan rombak Job Engine, Dispatcher, Cluster, Creative AI, Workforce, atau Queue.
Jangan membuat Scheduler, Marketplace, Billing, Video, Voice, OCR, atau Plugin.
Semua perubahan harus additive, modular, backward compatible, OpenAPI-first, dan wajib lolos pnpm run verify.

BAGIAN 1 — EVENT STORE
======================

Buat tabel:

ai_events

Field:

* id
* event_id
* event_type
* source_module
* source_id
* correlation_id
* causation_id
* payload_json
* metadata_json
* status
* published_at
* processed_at
* created_at

Status:

* pending
* published
* processing
* processed
* failed
* ignored

====================================================================
BAGIAN 2 — EVENT SUBSCRIPTIONS
==============================

Buat tabel:

ai_event_subscriptions

Field:

* id
* subscription_name
* event_type
* target_type
* target_id
* handler_type
* handler_config_json
* status
* retry_policy
* created_at
* updated_at

Contoh subscription:

* creative.project.completed → create marketing job
* creative.client.approved → notify admin
* job.failed → audit alert
* worker.stale → recovery job
* image.approved → export asset package

====================================================================
BAGIAN 10 — AUDIT & SAFETY
==========================

Semua event penting harus audit logged:

* event published
* event processed
* event failed
* event replayed
* subscription created/updated/deleted

Safety:

* event processing idempotent
* replay aman
* handler failure tidak crash dispatcher
* correlation_id wajib dibuat jika kosong
* causation_id dipakai jika event berasal dari event lain
