1. PROVIDER CONTRACT
========================================================

Create a provider-independent interface.

Example responsibilities:

- provider identity
- supported brands
- supported countries or regions
- source type
- capability declaration
- fetch catalog metadata
- fetch catalog items
- validate configuration
- health/status result

The interface must not assume any specific vendor or website.

Suggested shape:

interface MaterialCatalogProvider {
  readonly providerId: string;
  readonly displayName: string;
  readonly sourceType: "official_api" | "official_feed" | "manual_fixture";

  getCapabilities(): CatalogProviderCapabilities;

  validateConfig(
    config: unknown
  ): Promise<CatalogProviderValidationResult>;

  fetchCatalog(
    context: CatalogFetchContext
  ): Promise<ExternalCatalogResult>;
}

Do not use unstructured text as the primary contract.

All input and output must be typed and schema-validated.
