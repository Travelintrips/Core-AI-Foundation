TEAM 24 — FASHION DESIGN DOMAIN PLUGIN

BRANCH WAJIB:
feature/team-24-fashion-plugin

==================================================
TUJUAN
==================================================

Bangun Fashion Design Plugin pertama sebagai implementasi domain di atas
Universal Design Engine.

Plugin harus menggunakan core contracts.

Jangan memasukkan field Fashion ke core platform.

==================================================
SCOPE
==================================================

Bangun:

- plugin manifest;
- fashion brief schema;
- workflow definition;
- artifact type registry;
- capability contribution;
- material category contribution;
- component category contribution;
- property section contribution;
- renderer metadata contribution;
- export presets;
- domain examples;
- tests;
- documentation.

==================================================
WORKFLOW
==================================================

Minimal workflow:

1. Brief
2. Research/Reference
3. Moodboard
4. Creative Direction
5. Concept Sketch
6. Technical Drawing
7. Colorway
8. Material Assignment
9. Visualization
10. Review
11. Export

Workflow harus configurable.

Jangan membuat execution engine kedua.

==================================================
BRIEF
==================================================

Minimal fields dapat mencakup:

- product category;
- target user;
- season;
- style direction;
- silhouette;
- color direction;
- material preference;
- size range;
- market segment;
- production constraints;
- sustainability;
- reference assets.

Gunakan schema plugin, bukan core fields.
