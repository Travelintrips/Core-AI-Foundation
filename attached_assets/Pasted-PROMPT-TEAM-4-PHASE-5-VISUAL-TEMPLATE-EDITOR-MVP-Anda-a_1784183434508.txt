State Model

Gunakan satu canonical editor state.

Minimal:

type EditorState = {
  templateId: string;
  baseVersionId?: string;
  canvas: CanvasDefinition;
  elements: DesignElement[];
  variables: TemplateVariable[];
  selectedElementIds: string[];
  sampleData: Record<string, unknown>;
  dirty: boolean;
  history: EditorHistory;
};

Jangan menyimpan binary image di state.

Gunakan asset IDs atau safe URLs.

Serialization

Editor harus:

load template JSON,
normalisasi schema,
render ke canvas,
edit,
serialize kembali ke schema backend,
validate sebelum save.

Jangan menyimpan Fabric/Konva internal JSON sebagai canonical template JSON jika berbeda dari domain schema.

Buat adapter:

DesignTemplate JSON
↔
Editor Scene Model

Tambahkan round-trip tests.

Implementasikan bounded history.

Save dan Versioning

Save draft:

validate,
kirim template JSON,
buat draft version baru sesuai API contract existing,
tidak mengubah published version.

Jika backend hanya mendukung create version, gunakan endpoint tersebut.

Jangan mengedit immutable version.

Tambahkan autosave hanya jika aman. Untuk MVP, explicit save lebih baik daripada autosave yang berisiko.

Backend Preview

Tombol Preview harus menggunakan:

POST /api/ai/design-templates/:id/preview

Kirim current unsaved template hanya jika backend mendukung preview draft payload secara aman. Jika tidak, save draft dulu lalu preview version.

Jangan menganggap canvas frontend identik dengan final render.

Tampilkan label:

Final Renderer Preview
Publish

Editor boleh memanggil publish endpoint setelah save.

Sebelum publish:

validate,
pastikan tidak ada required variable invalid,
tampilkan confirmation,
jelaskan immutable version.
