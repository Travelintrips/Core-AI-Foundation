8. VERIFY CONFIDENCE

Periksa mapping score → confidence.

Pastikan:

low untuk fallback atau sinyal lemah;
confidence tidak bergantung pada urutan array;
unknown industry tidak diberi high confidence tanpa alasan lain yang kuat.

Dokumentasikan threshold nyata yang digunakan.

pastikan legacy parser masih bekerja.

Jangan menyimpan object recommendation ke field backend string.

13. VERIFY AUTOSAVE

Periksa browser network atau test harness.

Expected:

Saat engine menghitung ulang recommendation
0 autosave request
Saat user membuka recommendation panel
0 autosave request
Saat user menekan Gunakan
1 state change
→ autosave existing setelah debounce
Saat user menekan Gunakan Semua
1 consolidated brief update
→ bukan satu request per recommendation

Pastikan tidak ada:

infinite autosave loop;
autosave karena generatedAt;
autosave karena memo/result object berubah;
duplicate save request;
save pada initial hydration.
