TUGAS 1 — SELESAIKAN CODE REVIEW
==========================================================

Jalankan kembali mandatory code review.

Periksa khusus:

1. Customer tidak menerima:
   - estimated_ai_cost
   - actual_ai_cost
   - human_labor_estimate
   - gross_margin
   - gross_margin_percentage
   - internal provider/model metadata

2. Semua nilai harga dari request body tidak boleh dipercaya langsung.
   Backend wajib menghitung ulang menggunakan aiPricingService.

3. Customer tidak boleh mengubah:
   - base price
   - discount internal
   - tax rate
   - margin
   - package price
   - price rule result

4. Price rule harus:
   - deterministic
   - memiliki priority
   - tidak diaplikasikan dua kali
   - tersimpan dalam pricing snapshot

5. Semua monetary fields harus konsisten:
   - gunakan integer rupiah atau decimal yang aman
   - jangan memakai floating point mentah untuk kalkulasi uang

6. Seed harus idempotent dan tidak membuat duplikasi.

7. Customer route tidak boleh memakai admin API key secara terbuka di browser.

Fix semua temuan yang terkait implementasi ini secara minimal dan aman.

TUGAS 6 — CONVERSION KE ACTIVE PROJECT
==========================================================

Project aktif hanya dibuat jika:

- quotation status approved
- commercial gate status verified atau waived
- service request belum pernah dikonversi

Conversion harus idempotent.

Saat conversion:

1. Buat active project
2. Simpan service_request_id dan quotation_id
3. Buat execution plan
4. Enqueue jobs
5. Publish event:
   - service_request.approved
   - commercial_gate.verified
   - service_request.converted
   - project.created
6. Update service request ke converted_to_project
7. Simpan project_id di service request

Gunakan transaction agar tidak membuat duplicate project atau duplicate jobs.
