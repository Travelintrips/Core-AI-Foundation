Perbaiki Demo Portfolio Sample Pipeline.

KONDISI SAAT INI:

Pada Portfolio Center terdapat portfolio berstatus published seperti:

“Kopi Senja — Coffee Shop Logo”

Tetapi detail menunjukkan:

- No preview image
- No assets attached
- QC Score kosong

Sebelumnya sample image dikonfigurasi expired 1 jam.

Ini tidak sesuai kebutuhan bisnis.

Saya membutuhkan dua kebijakan asset yang berbeda:

1. LIVE AI PREVIEW
- temporary
- low resolution
- watermark
- expired 1 jam
- tidak boleh digunakan komersial

2. DEMO PORTFOLIO SAMPLE
- permanent
- disimpan di Object Storage
- tidak expired
- tampil di public portfolio gallery
- dapat digunakan sebagai materi pemasaran
- original tetap private
- public hanya memakai thumbnail/optimized preview

PENTING:

Jangan membuat portfolio pipeline baru.
Reuse Portfolio Generator, Image Designer, Queue, Dispatcher,
Archive Worker, Object Storage, QC, dan Admin Review yang sudah ada.

==========================================================
1. PISAHKAN ASSET POLICY
==========================================================

Tambahkan atau pastikan field:

asset_purpose

Enum:

- live_preview
- demo_portfolio
- customer_preview
- customer_final

Policy:

live_preview:
- expires_at default 1 jam
- watermark
- low resolution
- temporary
- auto cleanup

demo_portfolio:
- expires_at null
- permanent storage
- optimized public preview
- original private
- tidak dihapus otomatis

customer_preview:
- private
- watermark
- signed access
- tidak final

customer_final:
- private permanent
- signed download
- payment gated

Jangan gunakan expiry 1 jam untuk demo_portfolio.

==========================================================
2. AUDIT PORTFOLIO TANPA ASSET
==========================================================

Cari seluruh portfolio yang:

- status published
- cover_asset_id null
- gallery kosong
- tidak memiliki portfolio asset
- QC score null
- memakai temporary provider URL yang expired

Untuk setiap record:

- tandai status needs_repair
- jangan tampilkan di public gallery
- jangan hapus record secara otomatis
- masukkan ke Repair Queue

- Kopi Senja
- Bloom & Co

periksa apakah hanya metadata seed tanpa gambar nyata.

==========================================================
3. PUBLICATION GUARD
==========================================================

Portfolio tidak boleh menjadi published jika:

- assets count < minimum required
- cover asset belum ada
- asset archive status bukan archived/optimized
- URL masih Replicate temporary URL
- QC score null
- QC score < 80
- trademark risk bukan low
- admin belum approve

Tambahkan database/service state-machine guard.

Jangan hanya mengandalkan frontend.

==========================================================
5. NON-BLOCKING ARCHIVING
==========================================================

Jangan menunggu upload storage di proses utama generation.

Flow:

Generate image
→ insert portfolio asset dengan status generated
→ enqueue archive_asset job
→ portfolio tetap status generating_assets/review
→ archive worker download dari Replicate
→ upload ke Object Storage
→ update permanent URL
→ enqueue thumbnail/optimization
→ QC
→ admin review
→ publish

Archive harus berjalan melalui Queue/Dispatcher existing.

Jangan memakai fire-and-forget Promise yang tidak tercatat.

Gunakan durable job dengan idempotency key.

==========================================================
6. ARCHIVE JOB
==========================================================

Tambahkan/reuse job type:

archive_portfolio_asset

Payload:

- portfolio_id
- asset_id
- source_url
- destination_key
- expected_mime_type

Job harus:

- validasi source URL
- download dengan timeout
- batasi ukuran
- validasi MIME
- upload ke Object Storage
- update asset record secara transaction-safe
- retry exponential backoff maksimal 3 kali
- tidak menggandakan file pada replay
- publish asset.archived event

Status gagal:

archive_failed

Portfolio tetap tidak boleh published.

==========================================================
7. STORAGE PATH
==========================================================

Gunakan pola permanen:

public/demo-portfolios/{portfolioId}/{assetId}/preview.webp

private/demo-portfolios/{portfolioId}/{assetId}/original.webp

thumbnail:

public/demo-portfolios/{portfolioId}/{assetId}/thumb.webp

Jangan menyimpan seluruh URL sebagai source of truth.

Simpan storage key.

Public preview URL dapat dibentuk dari storage service.
