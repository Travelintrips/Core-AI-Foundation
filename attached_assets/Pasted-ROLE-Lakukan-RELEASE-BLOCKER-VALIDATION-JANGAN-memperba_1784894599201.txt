- apakah repository history memang masih mengandung credential

Tenant Isolation

tidak memiliki tenant predicate.

Validasi:

- apakah tenant filtering dilakukan langsung di query

atau

- dilakukan oleh middleware

atau

atau

- dilakukan oleh security layer

Jangan berhenti di route.

Jika tenant sudah dijamin oleh layer lain,

jangan laporkan sebagai blocker.

==================================================
BLOCKER 4
==================================================

Background Image Pipeline

Audit sebelumnya menyebut:

HTTP 202 dikembalikan sebelum pipeline selesai.

Validasi:

- bagaimana lifecycle project berubah ketika pipeline gagal

- apakah ada retry

- apakah ada audit log

- apakah ada failed state

- apakah customer dapat mengetahui kegagalan

Jika pipeline memang asynchronous by design,

tentukan apakah implementasinya sudah benar.

Jangan menganggap async = bug.
