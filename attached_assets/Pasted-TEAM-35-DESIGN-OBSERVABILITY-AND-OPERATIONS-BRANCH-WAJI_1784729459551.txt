==================================================
TUJUAN
==================================================

Bangun observability layer untuk Universal Design Platform.

Harus memungkinkan admin melihat:

- workflow health;
- job status;
- stage latency;
- failure rate;
- retry;
- stuck jobs;
- renderer failures;
- AI provider failures;
- QC failure;
- export failures;
- cost anomalies;
- event stream health;
- plugin health.

Gunakan AI Operations Center dan telemetry pattern existing.

Jangan membuat monitoring platform kedua.

==================================================
INCIDENT DETECTION
==================================================

Dukung rule-based detection:

- job stuck;
- repeated provider failure;
- renderer failure spike;
- queue growth;
- timeout spike;
- cost anomaly;
- missing worker;
- plugin load failure;
- event stream lag;
- invalid output spike.

Jangan membuat auto-remediation berbahaya.
