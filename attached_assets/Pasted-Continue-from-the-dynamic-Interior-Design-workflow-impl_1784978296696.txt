Continue from the dynamic Interior Design workflow implementation.

Do not modify the commercial lifecycle, payment flow, workflow dispatcher, or existing Generate Images route.

OBJECTIVE

Make the structured Interior Design concept editable before image rendering.

The current Interior Design output includes:

- moodboard
- visualConcept
- spacePlan
- furniturePlacement
- materialRecommendations
- lightingRecommendations

These outputs must no longer be display-only.

PHASE 1 — AUDIT CURRENT DATA MODEL

Inspect:

- Interior Design project detail page
- existing output JSON structure
- database tables storing Interior Design output
- API routes used by /interior-design/{projectId}
- reusable components integrated into /creative-ai

Report the current source of truth for:

- spacePlan
- furniturePlacement
- materialRecommendations
- lightingRecommendations

Do not create duplicate storage if these fields already exist.

PHASE 2 — EDITABLE SPACE PLANNING

Allow admin to edit each space planning item:

- zone/room name
- function
- approximate size
- priority
- adjacency or relationship to other rooms
- notes

Support:

- add zone
- edit zone
- remove zone
- reorder zone
- save draft
- cancel unsaved changes

Do not require image regeneration when saving these edits.

PHASE 3 — EDITABLE MATERIAL SPECIFICATION

- area/room
- component
- material category
- material type
- color
- finish
- texture
- optional brand
- optional product code
- price tier
- notes
- selected/rejected status

Provide controlled dropdown options for common material categories, but also allow a Custom option.

- epoxy

PHASE 5 — SAVE AND VERSIONING

Create or reuse an authenticated API to update the structured Interior Design concept.

Requirements:

- tenant/project authorization
- schema validation
- optimistic concurrency or updatedAt check
- audit log
- save editor identity and timestamp
- preserve the original AI-generated output
- store edited output as the current approved draft
- do not silently overwrite customer-approved data

Prefer a versioned structure such as:

- aiGeneratedVersion
- currentDraftVersion
- approvedVersion

Use the existing project output model where possible.

PHASE 6 — REVIEW STATE

Add clear states:

- AI Generated
- Edited by Admin
- Ready for Customer Review
- Revision Requested
- Approved for Rendering

Generate Images must only use the latest approved or explicitly selected draft.

If there is an unsaved edit, disable Generate Images or warn the user.

PHASE 7 — IMAGE PROMPT INTEGRATION

Trace how runImageDesignerPipeline builds its prompt.

- space plan
- selected materials
- furniture placement
- lighting
- visual concept

It must not use stale original AI output after edits have been saved.

Do not automatically run image generation after saving an edit.
