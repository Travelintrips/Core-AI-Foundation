==========================================================
TAHAP 1 — INSPEKSI SMOKE TEST
==========================================================

Periksa portfolio dan seluruh asset hasil smoke test.

Verifikasi:

1. Portfolio row tersimpan lengkap.
2. portfolio_code dan slug unik.
3. Brand name fiktif dan tidak menduplikasi brand lain.
4. synthetic/demo flag aktif.
5. Label “AI Demo Project” tersedia.
6. Industry, style, package, dan service benar.
7. Cover asset terhubung.
8. Semua asset memiliki relasi portfolio_id yang benar.
9. Provider dan model tercatat internal.
10. Cost tercatat benar.
11. Tidak ada storage_path atau metadata internal dalam public DTO.

Tampilkan daftar asset:

- asset type
- asset role
- status
- provider
- model
- dimensions
- file size
- preview URL availability
- QC score
- QC notes
- storage state

==========================================================
TAHAP 2 — VALIDASI FILE GAMBAR NYATA
==========================================================

Pastikan asset benar-benar berupa file gambar yang dapat dibuka,
bukan hanya prediction ID, placeholder URL, atau URL provider sementara.

Periksa:

- image_url tersedia
- HTTP response gambar valid
- mime type benar
- file tidak kosong
- width/height masuk akal
- thumbnail tersedia
- preview tersedia
- original tersimpan private jika storage integration aktif

Jika URL Replicate bersifat sementara:

- download asset ke storage internal
- simpan storage_path internal
- buat thumbnail/preview
- jangan expose URL asli Replicate sebagai permanent public asset

==========================================================
TAHAP 3 — VISUAL QUALITY REVIEW
==========================================================

Buka semua gambar hasil smoke test dan lakukan review visual.

Nilai:

- kesesuaian dengan industry
- kesesuaian dengan style
- konsistensi antar-asset
- kualitas logo
- kualitas mockup
- komposisi
- artefak visual
- teks rusak/gibberish
- penggunaan warna
- keterbacaan
- kelayakan ditampilkan ke calon customer

Jangan hanya mengandalkan status completed dari API.

Gunakan penilaian:

- PASS
- PASS_WITH_MINOR_FIX
- REGENERATE
- REJECT

Berikan alasan konkret untuk setiap asset.

==========================================================
TAHAP 4 — ASSET COMPLETENESS
==========================================================

Pastikan smoke portfolio memiliki minimum:

1. Logo concept
2. Color palette
3. Typography direction
4. Main brand mockup
5. Social media visual 1
6. Social media visual 2

Jika pipeline saat ini hanya membuat satu gambar:

JANGAN menjalankan batch 30.

Perbaiki generator agar satu portfolio menghasilkan seluruh required assets.

Setiap asset harus memakai prompt yang sesuai dengan role-nya,
bukan satu gambar yang diduplikasi menjadi beberapa jenis asset.

==========================================================
TAHAP 5 — LOGO & TEXT POLICY
==========================================================

Model image sering menghasilkan teks/logo yang rusak.

Terapkan strategi:

- jangan mengandalkan image model untuk teks panjang
- buat wordmark/logo text melalui SVG/layout layer jika diperlukan
- gunakan image model untuk visual direction dan mockup
- overlay nama brand dengan renderer terkontrol untuk hasil portfolio
- jangan publish mockup dengan gibberish text

Jika logo final belum cukup konsisten:

- tandai sebagai conceptual logo
- jangan klaim vector/source-ready
- masukkan ke admin review

==========================================================
TAHAP 6 — QC DAN TRADEMARK SAFETY
==========================================================

Verifikasi:

- QC score benar-benar berasal dari evaluasi, bukan nilai default
- trademark risk dinilai
- duplicate-name check berjalan
- kemiripan nama/visual dengan merek terkenal diperiksa
- risk medium/high masuk review dan tidak auto-publish

Minimum publish rule:

- QC score >= 80
- trademark risk = low
- seluruh required assets tersedia
- cover tersedia
- tidak ada artefak fatal
- tidak ada gibberish text signifikan
- admin approved

==========================================================
TAHAP 7 — PERBAIKI SMOKE TEST JIKA DIPERLUKAN
==========================================================

Jika ada masalah:

- perbaiki hanya generator/QC/storage yang terkait
- jangan rewrite Portfolio System
- jangan membuat pipeline kedua
- gunakan Queue, Dispatcher, Creative AI, Image Designer,
  Storage, Cost Tracking, dan Review Queue yang sudah ada

Setelah perbaikan:

- hapus/archive throwaway smoke portfolio secara aman
- jalankan satu smoke test baru
- ulangi pemeriksaan sampai PASS
