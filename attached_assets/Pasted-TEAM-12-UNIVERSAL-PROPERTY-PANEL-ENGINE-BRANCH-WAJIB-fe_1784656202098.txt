TEAM 12 — UNIVERSAL PROPERTY PANEL ENGINE

BRANCH WAJIB:
feature/team-12-property-panel

==================================================
TUJUAN
==================================================

Bangun Property Panel universal untuk Universal Design Workspace.

Property Panel harus dapat menampilkan dan mengubah properti:

- project;
- artifact;
- frame/view;
- selected element;
- selected region;
- layer;
- material assignment;
- typography;
- dimensions;
- metadata;
- review status;
- plugin extension properties.

Property Panel harus domain-neutral.

Dilarang membuat panel khusus Fashion, Interior, Packaging, atau Branding di core.

==================================================
DEPENDENCY
==================================================

Team 11 menyediakan Canvas Workspace dan selection events.

Jika kontrak Team 11 belum tersedia:

- buat WorkspaceSelectionAdapter minimal;
- gunakan stable opaque IDs;
- jangan membuat Canvas Workspace kedua;
- dokumentasikan penggantian adapter saat integrasi.

Gunakan @workspace/design-contracts jika tersedia.

==================================================
PROPERTY REGISTRY
==================================================

Registry harus:

- menerima section dari core dan plugin;
- menolak duplicate ID;
- mempunyai ordering;
- mendukung visibility condition;
- mendukung read-only condition;
- mendukung capability requirement;
- mendukung feature stability;
- menghasilkan diagnostic bila renderer tidak tersedia.

Dilarang membuat switch besar berdasarkan service type.

==================================================
EDITING MODEL
==================================================

Pisahkan:

1. canonical current values;
2. local draft;
3. dirty fields;
4. validation state;
5. pending save;
6. save failure;
7. conflict state.

Dukung:

- immediate update;
- explicit save;
- autosave optional;
- cancel/reset;
- partial patch;
- optimistic concurrency token;
- stale version conflict;
- permission denied;
- read-only artifact.

Jangan menyimpan seluruh artifact baru untuk perubahan satu field jika backend
mendukung patch.

==================================================
VALIDATION
==================================================

Gunakan schema dari plugin/contract.

Validation wajib:

- field-level;
- section-level;
- cross-field bila disediakan schema;
- human-readable errors;
- tidak menampilkan raw Zod error;
- invalid values tidak dikirim;
- numeric bounds;
- required condition;
- enum restriction;
- unsafe string handling.

==================================================
SELECTION INTEGRATION
==================================================

Property Panel harus merespons:

- selectedArtifactId;
- selectedFrameId;
- selectedElementId;
- selectedRegionId;
- selectedLayerId.

Selection ID bersifat opaque.

Core tidak boleh memahami arti sleeve, wall, box-panel, logo-mark, atau sofa.

==================================================
PLUGIN EXTENSION
==================================================

Plugin dapat mendaftarkan:

- property sections;
- field schemas;
- field renderers;
- validation;
- visibility condition;
- capability requirement;
- default values.

Plugin tidak boleh mengimpor internal state Property Panel.

Gunakan public registry API.

==================================================
SECURITY
==================================================

- Jangan render raw HTML.
- Jangan percaya label dari plugin tanpa sanitization.
- Jangan expose secret metadata.
- Jangan gunakan tenantId dari client sebagai authority.
- Jangan kirim field yang tidak diizinkan.
- Jangan memungkinkan arbitrary component/module loading dari URL.
