2. Add Provider Guardrails
   Tambahkan konfigurasi:

* max_cost_per_workflow
* max_cost_per_request
* max_retry_per_provider
* provider_timeout_ms
* disable_provider_on_error_rate
* fallback_enabled

3. Upgrade intelligentRouter
   Router harus mempertimbangkan:

* capability matrix
* historical success
* average latency
* average cost
* provider health
* guardrail settings
* max context
* workflow budget

4. Add Execution Safety
   Jika estimated cost melewati budget:

* stop execution
* mark step as blocked_by_budget
* tampilkan error jelas di UI
* audit log harus tersimpan

Jika provider timeout:

* retry sesuai limit
* fallback jika enabled
* simpan retry_count dan fallback_count

Endpoint ini membuat beberapa sample Creative AI projects untuk testing:

Tujuan:
