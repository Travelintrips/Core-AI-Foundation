==================================================

artifacts/api-server/src/routes/coding-workspace.ts

==================================================
4. BUTTON BEHAVIOR
==================================================

Saat user klik Run Agent:

POST /api/ai/coding/tasks/{task.id}/run

Saat request berjalan:

- disable tombol
- tampilkan state loading
- cegah double click

Saat sukses:

- invalidate/refetch coding task detail
- invalidate/refetch Agent Runs jika query terpisah
- UI harus langsung menampilkan run baru

Expected run:

Agent:
Repository Analyzer

Status:
RUNNING


==================================================
5. ERROR HANDLING
==================================================

Jika POST gagal:

- jangan mengubah task secara manual menjadi ANALYZING
- tampilkan error/toast
- tombol kembali aktif

Status ANALYZING harus berasal dari backend `/run`, bukan PATCH frontend.


==================================================
6. IDEMPOTENCY / DOUBLE CLICK
==================================================

Audit route:

artifacts/api-server/src/routes/coding-workspace.ts

Pastikan double click / repeated POST tidak membuat dua active run untuk task yang sama.

Jika backend SUDAH mempunyai proteksi tersebut:
jangan ubah.

Jika belum:
tambahkan guard minimal agar task yang sudah memiliki active run RUNNING tidak membuat duplicate active run.

Jangan merusak historical completed/failed runs.
