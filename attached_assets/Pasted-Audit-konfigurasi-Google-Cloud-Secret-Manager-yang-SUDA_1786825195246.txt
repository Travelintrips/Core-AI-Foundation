Audit konfigurasi Google Cloud Secret Manager yang SUDAH ADA di repository ini.

Jangan membuat loader baru sebelum memastikan implementasi existing.

Target konfigurasi yang ingin digunakan:

* GCP Project: `aicore-505614`
* Secret Manager Secret ID: `aicore-app-secrets`
* Replit hanya akan menyimpan satu bootstrap credential:
  `GCP_SECRET_MANAGER_BOOTSTRAP_JSON`
* Application secrets lainnya harus dibaca dari Google Cloud Secret Manager.
* Jangan pernah mencetak, menampilkan, atau memasukkan nilai secret/private key ke log atau laporan.

Lakukan end-to-end:

1. Cari seluruh repository untuk:

   * `GCP_SECRET_MANAGER_BOOTSTRAP_JSON`
   * `GOOGLE_SECRET_MANAGER_SERVICE_ACCOUNT_JSON`
   * `GCP_PROJECT_ID`
   * `GCP_SECRET_ID`
   * `SecretManagerServiceClient`
   * `@google-cloud/secret-manager`
   * `accessSecretVersion`
   * `secretmanager`
   * loader/bootstrap/config startup terkait Google Cloud Secret Manager.

2. Identifikasi:

   * file loader yang sebenarnya digunakan;
   * entrypoint yang memanggil loader;
   * kapan loader dijalankan;
   * environment variable yang benar-benar dibaca;
   * apakah DEV dan PROD menggunakan loader yang sama atau berbeda.

3. Laporkan path file loader existing secara jelas.

4. Jika loader existing masih menggunakan:
   `GOOGLE_SECRET_MANAGER_SERVICE_ACCOUNT_JSON`

   migrasikan dengan aman agar canonical bootstrap variable menjadi:

   `GCP_SECRET_MANAGER_BOOTSTRAP_JSON`

5. Sederhanakan bootstrap sehingga Replit cukup membutuhkan:

   `GCP_SECRET_MANAGER_BOOTSTRAP_JSON`

   Gunakan konfigurasi non-secret canonical:

   * project ID: `aicore-505614`
   * secret ID: `aicore-app-secrets`

   Jangan menyimpan private key atau credential apa pun di source code.

6. Loader harus menggunakan service-account JSON dari:
   `process.env.GCP_SECRET_MANAGER_BOOTSTRAP_JSON`

   untuk mengautentikasi ke Google Cloud dan membaca:

   `projects/aicore-505614/secrets/aicore-app-secrets/versions/latest`

7. Setelah payload berhasil dibaca:

   * parse JSON dengan aman;
   * expose application secrets ke runtime sesuai mekanisme existing;
   * jangan overwrite bootstrap credential;
   * jangan log nilai secret.

8. Fail closed jika:

   * bootstrap JSON tidak tersedia;
   * JSON invalid;
   * authentication gagal;
   * permission Secret Manager gagal;
   * `aicore-app-secrets` tidak ditemukan;
   * latest version tidak dapat dibaca;
   * payload bukan JSON valid.

9. Test koneksi secara nyata menggunakan environment Replit saat ini.

   Verifikasi hanya:

   * authentication PASS/FAIL;
   * project ditemukan;
   * secret ditemukan;
   * latest version dapat dibaca;
   * JSON dapat diparse;
   * nama/key konfigurasi yang diperlukan tersedia.

   JANGAN tampilkan value dari secret apa pun.

10. Jalankan test/typecheck/build yang relevan setelah perubahan.

11. Jangan berhenti hanya pada audit apabila masalah teknis dapat diperbaiki dengan aman. Audit → perbaiki → test → selesaikan end-to-end.

12. Jangan mengubah business logic atau modul yang tidak berhubungan dengan Secret Manager.

Output akhir harus menunjukkan:

* loader file path;
* startup/entrypoint path;
* bootstrap env var yang digunakan;
* GCP project;
* Secret ID;
* IAM/access test;
* Secret Manager read test;
* JSON parse test;
* application secret loading test;
* test/typecheck/build;
* file yang diubah;
* final verdict PASS/FAIL.

Jangan pernah tampilkan nilai API key, password, database credential, service-account private key, token, atau secret lainnya dalam output.
