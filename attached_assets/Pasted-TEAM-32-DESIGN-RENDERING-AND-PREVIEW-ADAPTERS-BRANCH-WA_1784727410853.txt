TEAM 32 — DESIGN RENDERING AND PREVIEW ADAPTERS

BRANCH WAJIB:
feature/team-32-design-rendering

==================================================
TUJUAN
==================================================

Bangun adapter universal antara artifact design dan renderer/preview engine.

Team 32 tidak membuat semua renderer dari nol.

Gunakan engine existing bila tersedia:

- image generation;
- document renderer;
- presentation renderer;
- PDF preview;
- thumbnail generator;
- storage delivery;
- external rendering provider melalui AI execution layer.

==================================================
RENDER TARGET
==================================================

Target dapat berupa:

- artifact preview;
- thumbnail;
- workspace image;
- review preview;
- document page;
- presentation slide;
- technical preview;
- mockup preview;
- 3D preview placeholder/descriptor.

Jangan mengklaim 3D render tersedia jika engine tidak tersedia.

==================================================
REGISTRY
==================================================

Registry harus:

- unique renderer ID;
- capability-based resolution;
- deterministic priority;
- format validation;
- input compatibility;
- output profile;
- timeout;
- retryability;
- explicit unavailable state;
- no arbitrary module loading.

==================================================
RENDER PROFILE
==================================================

Dukung metadata:

- width;
- height;
- pixel ratio;
- quality;
- background;
- transparency;
- format;
- page/frame;
- color profile metadata;
- purpose;
- max file size;
- preview/full quality distinction.

Jangan memaksakan resolusi tinggi untuk semua preview.

==================================================
HONESTY
==================================================

Wajib membedakan:

- native conversion;
- rasterized preview;
- spec-rendered preview;
- generated approximation;
- unavailable;
- placeholder.

Jangan memberi label “converted PDF” bila bukan hasil conversion nyata.

==================================================
SECURITY
==================================================

- sanitized file name;
- no raw internal storage path;
- signed URL;
- tenant isolation;
- input type validation;
- no arbitrary executable payload;
- no untrusted HTML injection;
- no arbitrary renderer command;
- resource limits.
