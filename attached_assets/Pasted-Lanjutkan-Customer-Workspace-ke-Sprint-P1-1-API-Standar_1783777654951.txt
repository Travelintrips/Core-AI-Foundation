=========================================================
5. WORKSPACE TOKEN HARDENING
=========================================================

Audit workspace token.

Pastikan:

- token dibuat dengan randomBytes yang kuat
- token asli hanya ditampilkan satu kali
- database menyimpan hash, bukan plaintext
- expiry tersedia
- revoke tersedia
- rotate tersedia
- token lama langsung invalid setelah rotate
- token tidak masuk application log
- token tidak masuk audit payload
- token tidak masuk analytics URL
- error invalid/expired/revoked aman

Tambahkan admin endpoint jika belum ada:

POST /api/ai/customer-workspace/customers/:customerId/rotate-token

Response:
- token baru hanya sekali
- expiresAt
- audit reference

9. INVOICE DOWNLOAD SECURITY
=========================================================

Gunakan signed URL.

Aturan:

- token expired
- token revocable
- scope token hanya ke satu dokumen

- download masuk audit
- storage path tidak tampil ke client

Tambahkan endpoint berdasarkan route convention existing:

GET invoice document metadata
POST generate/regenerate invoice
GET signed invoice access

Admin-only regenerate harus memiliki alasan audit.
