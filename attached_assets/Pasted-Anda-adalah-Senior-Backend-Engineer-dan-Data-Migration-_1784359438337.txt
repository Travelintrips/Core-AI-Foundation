====================================================
PHASE 2 — CANONICAL NORMALIZATION
====================================================

Buat normalisasi terpusat dan reusable.

Contoh canonical style:

"Modern"       → "modern"
"Minimalist"   → "minimalist"
"Elegant"      → "elegant"
"Professional" → "professional"
"Promotional"  → "promotional"

Contoh canonical industry:

"Technology" → "technology"
"Teknologi"  → "technology"
"F&B"        → "food_beverage"
"Property"   → "real_estate"
"Export"     → "trading"
"Trading"    → "trading"
"Logistics"  → "logistics"

Aturan:

1. Buat canonical alias map terpusat.
2. Jangan membuat mapping tersebar di banyak file.
3. Normalizer harus:
   - trim whitespace
   - lowercase
   - normalize separator
   - mendukung alias
   - fail safely untuk nilai tidak dikenal
4. Nilai tidak dikenal tidak boleh diam-diam dipetakan secara asal.
5. Laporkan unresolved values.

Gunakan normalizer yang sama untuk:

- seed
- matching
- filter
- backfill
- future template creation
