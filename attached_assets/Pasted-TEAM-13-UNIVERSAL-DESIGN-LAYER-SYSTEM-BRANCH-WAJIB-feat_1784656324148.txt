TEAM 13 — UNIVERSAL DESIGN LAYER SYSTEM

BRANCH WAJIB:
feature/team-13-layer-system

==================================================
TUJUAN
==================================================

Bangun Layer System universal untuk artifact design.

Layer System bukan image editor penuh.

Layer System V1 harus mampu:

- menampilkan hierarchy;
- select layer;
- toggle visibility;
- toggle lock;
- rename jika diizinkan;
- reorder;
- group/ungroup bila capability tersedia;
- expand/collapse;
- menunjukkan type/status;
- menyinkronkan selection dengan workspace;
- menerima layer contribution dari renderer/plugin.

==================================================
DOMAIN-NEUTRAL
==================================================

Core tidak boleh memiliki layer khusus:

- sleeve;
- wall;
- dieline panel;
- logo symbol;
- chair;
- landscape zone.

Gunakan generic LayerNode dengan extensions.

==================================================
STATE
==================================================

Pisahkan:

- canonical layer tree;
- UI expanded state;
- selected IDs;
- pending mutations;
- optimistic state;
- conflict/error state.

Jangan menyimpan React element dalam tree.

==================================================
OPERATIONS
==================================================

Dukung operation yang memiliki capability:

- select;
- show/hide;
- lock/unlock;
- rename;
- reorder;
- move;
- group;
- ungroup;
- duplicate;
- delete.

Jangan tampilkan action bila unsupported.

Jangan mengarang bahwa operation berhasil sebelum backend/adapter mengonfirmasi.

==================================================
VALIDATION
==================================================

Tolak:

- duplicate IDs;
- parent hilang;
- circular hierarchy;
- self-parent;
- invalid order;
- cross-artifact move tanpa izin;
- move ke descendant;
- mutation pada locked layer;
- mutation tanpa capability.

==================================================
UI
==================================================

Bangun reusable LayerPanel:

- hierarchical rows;
- indentation;
- expand/collapse;
- visibility button;
- lock button;
- selected state;
- optional drag-and-drop;
- context actions;
- empty/loading/error state;
- virtualization hanya bila diperlukan.

Jangan menambah drag-and-drop library besar tanpa audit.

Fallback gunakan move up/down jika lebih stabil.

==================================================

- keyboard navigation;

- up/down navigation;
- enter select;
- accessible toggle labels;
- focus indicator;
- action menu keyboard accessible.
