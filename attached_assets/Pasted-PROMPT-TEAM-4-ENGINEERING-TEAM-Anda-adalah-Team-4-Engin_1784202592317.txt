Agent 12 — JSON Architect AI

Tanggung jawab:

menggabungkan seluruh output agent;
memetakan component plan ke node editor;
membuat layer;
membuat position;
membuat size;
memasang variable binding;
memasang placeholder asset;
menerapkan typography;
menerapkan colors;
menerapkan decorations;
tidak membuat keputusan kreatif baru.

Output harus menggunakan schema editor yang sebenarnya.

Contoh konsep:

interface TemplateDocument {
  id: string;
  name: string;
  version: string;
  canvas: {
    width: number;
    height: number;
    background: string;
  };
  variables: unknown[];
  assets: unknown[];
  layers: unknown[];
  nodes: unknown[];
  metadata: {
    generatedBy: string;
    createdAt: string;
    pipelineVersion: string;
  };
}

Jangan memaksakan contoh ini jika schema repository berbeda.

Gunakan schema canonical repository.

Agent 13 — Validator AI

Validator harus sebagian besar deterministic code, bukan seluruhnya bergantung pada AI.

Periksa minimal:

duplicate ID;
invalid node type;
invalid layer;
missing layer;
invalid font;
invalid color;
invalid variable;
variable binding tidak ditemukan;
asset binding tidak ditemukan;
element out of bounds;
canvas overflow;
width atau height negatif;
opacity invalid;
invalid z-index;
duplicate z-index kritis;
overlap berbahaya;
CTA tertutup;
text terlalu kecil;
contrast rendah;
node tanpa parent jika schema memerlukannya;
unsupported property.

Output:

interface ValidationIssue {
  code: string;
  severity: "error" | "warning" | "info";
  nodeId?: string;
  field?: string;
  message: string;
  suggestedFix?: string;
}

interface ValidationReport {
  passed: boolean;
  score: number;
  errors: ValidationIssue[];
  warnings: ValidationIssue[];
  info: ValidationIssue[];
}

passed hanya true jika tidak ada error blocking.

Agent 14 — Optimizer AI

Optimizer tidak boleh:

mengganti campaign;

mengganti semua warna;
mengganti seluruh layout;
mengarang asset;
mengubah variable key tanpa migration mapping.

Output:

interface OptimizationResult {
  template: TemplateDocument;
  changes: Array<{
    type: string;
    nodeId?: string;
    before: unknown;
    after: unknown;
    reason: string;
  }>;
  unresolvedIssues: ValidationIssue[];
}

invalid JSON;
schema mismatch;
incomplete output;
provider timeout.

Deterministic validator tidak perlu retry.
