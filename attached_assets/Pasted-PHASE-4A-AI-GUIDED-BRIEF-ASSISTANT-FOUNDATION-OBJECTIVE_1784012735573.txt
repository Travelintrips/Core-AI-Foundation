PHASE 4A — AI GUIDED BRIEF ASSISTANT FOUNDATION
OBJECTIVE

Phase 1 sampai Phase 3.1 telah selesai.

Sekarang bangun pondasi AI Guided Brief Assistant untuk membantu user mengisi brief secara terstruktur.

Pada fase ini, assistant belum boleh memanggil OpenAI, Anthropic, Gemini, atau provider AI eksternal apa pun.

Assistant harus bekerja sepenuhnya menggunakan:

BriefData existing
Brief Intelligence Engine
brief-service-config
brief parser/serializer
existing autosave
existing validation
existing brief wizard

Tujuan Phase 4A:

Membuat assistant terstruktur berbasis rule dan quick replies yang sudah dapat membantu user melengkapi brief, menampilkan preview perubahan, meminta konfirmasi, lalu menerapkan jawaban ke form tanpa menimpa data existing.

Fase ini adalah foundation.

Backend AI integration akan dikerjakan di Phase 4B.

3. DOMAIN TYPES

Buat type terstruktur.

Contoh konsep:

type AssistantMode =
  | "start-from-beginning"
  | "complete-missing"
  | "show-recommendations";

type AssistantStage =
  | "idle"
  | "intro"
  | "question"
  | "preview"
  | "review"
  | "complete";

type AssistantQuestionType =
  | "single"
  | "multi"
  | "text"
  | "confirm";

type AssistantOption = {
  key: string;
  label: string;
  description?: string;
};

type PlannedBriefQuestion = {
  id: string;
  field: keyof BriefData;
  type: AssistantQuestionType;
  title: string;
  question: string;
  helperText?: string;
  options?: AssistantOption[];
  required: boolean;
  maxSelections?: number;
  reason: string;
  serviceType?: string;
};

type AssistantDraftChange = {
  field: keyof BriefData;
  previousValue: string;
  nextValue: string;
  displayBefore?: string[];
  displayAfter?: string[];
  conflict?: boolean;
  warnings: string[];
};

type AssistantConversationState = {
  mode: AssistantMode | null;
  stage: AssistantStage;
  currentQuestionId: string | null;
  answeredQuestionIds: string[];
  skippedQuestionIds: string[];
  pendingChange: AssistantDraftChange | null;
  completed: boolean;
};

Sesuaikan dengan bentuk codebase nyata.
