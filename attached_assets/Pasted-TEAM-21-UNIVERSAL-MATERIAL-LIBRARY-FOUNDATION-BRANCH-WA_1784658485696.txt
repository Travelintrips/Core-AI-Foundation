TEAM 21 — UNIVERSAL MATERIAL LIBRARY FOUNDATION

BRANCH WAJIB:
feature/team-21-material-library

==================================================
TUJUAN
==================================================

Bangun fondasi Material Library universal yang dapat digunakan oleh:

- Fashion;
- Interior;
- Furniture;
- Packaging;
- Architecture;
- Product Design;
- Jewelry;
- Landscape;
- domain design masa depan.

Material Library harus domain-neutral.

Jangan membuat implementasi yang hanya cocok untuk kain atau interior.

==================================================
SCOPE
==================================================

Bangun:

- canonical material contract;
- material category registry;
- property schema;
- material browser;
- material detail panel;
- filtering dan search;
- material assignment boundary;
- preview descriptor;
- plugin extension contract;
- test dan dokumentasi.

Jangan membuat renderer fisik, shader engine, atau simulation engine penuh.

==================================================
CATEGORY REGISTRY
==================================================

Registry harus:

- menolak duplicate ID;
- mendukung hierarchy;
- deterministic ordering;
- optional plugin ownership;
- capability metadata;
- feature stability;
- explicit unknown category handling.

Contoh kategori hanya sebagai fixture:

- textile;
- wood;
- metal;
- glass;
- plastic;
- paper;
- stone;
- ceramic;
- leather;
- composite;
- coating;
- finish;
- digital material.

Core tidak boleh membuat category-specific logic besar.

==================================================
PROPERTY SCHEMA
==================================================

Dukung property generik:

- text;
- number;
- boolean;
- enum;
- range;
- color;
- measurement;
- percentage;
- reference;
- texture asset;
- metadata.

Contoh data:

- weight;
- thickness;
- roughness;
- opacity;
- reflectivity;
- durability;
- stretch;
- fire rating;
- recyclability.

Semua contoh harus berada di category/plugin data, bukan mandatory core field.

==================================================
ASSIGNMENT BOUNDARY
==================================================

Expose contract untuk assignment:

- targetArtifactId;
- targetElementId atau regionId;
- materialId;
- materialVersion;
- assignment properties;
- override properties;
- source;
- capability;
- validation.

Jangan membuat garment, wall, floor, box-panel, atau furniture-specific target.

==================================================
SECURITY
==================================================

- tenant isolation;
- platform material scope explicit;
- no raw storage path;
- safe preview;
- no untrusted HTML;
- no arbitrary shader code;
- no arbitrary module loading;
- actor identity dari RequestContext;
- permission-aware update.
