TEAM 17 — UNIVERSAL DESIGN EXPORT WORKSPACE

BRANCH WAJIB:
feature/team-17-export-workspace

==================================================
TUJUAN
==================================================

Bangun Export Workspace universal untuk memilih dan menjalankan export artifact.

Team 17 membangun orchestration UI dan contract.

Jangan membuat renderer PDF/PPTX/image baru bila engine existing sudah tersedia.

==================================================
AUDIT
==================================================

Audit:

- Document Engine;
- Presentation Engine;
- image export;
- zip delivery;
- download/signed URL;
- jobs/workers;
- export status;
- thumbnails;
- artifact metadata;
- cost tracking;
- existing export buttons.

FEATURE

==================================================
FORMAT REGISTRY
==================================================

Buat ExportFormatRegistry.

Format dapat berasal dari engine/plugin.

Core tidak boleh hard-code semua kemampuan setiap domain.

Minimal contract:

ExportFormatDefinition
ExportPreset
ExportCapability
ExportRequest
ExportEstimate
ExportJobSummary
ExportResult
ExportValidationResult

==================================================
HONEST CAPABILITY
==================================================

Jika konversi tidak tersedia:

- tampilkan unavailable;
- jelaskan sebab;
- jangan membuat output palsu;
- jangan memberi label PDF conversion bila sebenarnya spec-rendered preview;
- pertahankan honesty pattern Presentation Engine.

==================================================
JOB INTEGRATION
==================================================

Gunakan AI Job Engine/worker/job patterns existing jika sesuai.

Jangan membuat polling engine kedua.

Dukung:

- queued;
- running;
- succeeded;
- failed;
- canceled;
- retrying.

Jangan membuat status palsu.

==================================================
SECURITY
==================================================

- no secret storage URL;
- signed download;
- permission;
- tenant isolation;
- sanitized filename;
- formula/CSV injection mitigation bila format tabular;
- no arbitrary renderer/module path;
- no direct provider call.
