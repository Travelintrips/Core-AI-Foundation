TEAM 23 — DESIGN KNOWLEDGE AND RECOMMENDATION ADAPTER

BRANCH WAJIB:
feature/team-23-design-knowledge

==================================================
TUJUAN
==================================================

Bangun adapter universal antara Design Platform dan knowledge systems existing.

Tujuan:

- mencari design knowledge;
- mengambil guideline;
- menemukan template/blueprint;
- menghubungkan style knowledge;
- menyediakan recommendation context;
- menjelaskan alasan rekomendasi;
- menjaga source attribution.

Jangan membuat vector database atau knowledge system kedua.

==================================================
PROVIDER REGISTRY
==================================================

Registry harus:

- tidak hard-code provider;
- deterministic priority;
- provider capability;
- timeout/error boundary;
- explicit unavailable state;
- dedup result;
- source attribution;
- tenant/platform scope.

Jangan memasukkan raw prompt atau provider secret ke output.

==================================================
RECOMMENDATION
==================================================

Recommendation harus:

- mempunyai reason;
- source;
- confidence;
- applicability;
- limitations;
- optional alternatives;
- tidak mengklaim fakta tanpa source;
- tidak otomatis mengubah project.

Recommendation hanya advisory sampai user/agent menerima melalui workflow canonical.
