# 4. Entitlement resolution

Jumlah output harus berasal dari order/package snapshot.

Urutan source of truth:

1. Service request pricing/package snapshot.
2. Package limits snapshot saat order dibuat.
3. Catalog package definition hanya sebagai fallback untuk legacy order.
4. Explicit custom quotation deliverables jika order custom.

Jangan menggunakan package name seperti `Basic`, `Standard`, atau `Premium` sebagai satu-satunya logic.

Contoh entitlement:

```ts
type ImageBatchEntitlement = {
  totalAssets: number;
  concepts?: number;
  variantsPerConcept?: number;
  platformBreakdown?: Array<{
    platform: string;
    placement: string;
    quantity: number;
    aspectRatio: string;
  }>;
  requiredViews?: string[];
  allowRegeneration: boolean;
  maxRegenerations?: number;
};
```

Simpan resolved entitlement di generation report.

# 5. Logo Design batch

Logo Design harus menghasilkan jumlah konsep sesuai entitlement.

Minimum target untuk paket yang menjanjikan tiga konsep:

* Concept A
* Concept B
* Concept C

Setiap konsep wajib berbeda secara nyata dalam:

* simbol atau icon direction
* composition
* typography direction
* visual style
* geometric structure
* brand mood

Jangan hanya mengganti warna.

## Prompt diversification

Bangun concept direction sebelum image generation.

Contoh direction:

```text
Concept A — Symbol-led geometric mark
Concept B — Wordmark-focused typographic identity
Concept C — Monogram or abstract letterform
```

Direction harus disesuaikan dengan brief customer.

Setiap concept memiliki:

* concept key
* concept name
* creative rationale
* visual direction
* prompt
* provider result
* QC result

## Output per concept

Minimal:

* primary preview
* PNG atau WebP
* background light
* background dark jika entitlement menjanjikan
* transparent output hanya jika provider benar-benar mendukung
* prompt metadata
* concept rationale

Jangan mengklaim SVG tersedia jika hanya raster.

## Completion

Logo batch hanya completed jika seluruh required concept tersedia.

Jika 3 konsep diwajibkan dan hanya 2 berhasil:

* project tidak completed
* batch status partial atau failed
* admin dapat retry hanya concept yang gagal

# 6. Logo duplicate detection

Implementasikan duplicate detection.

Gunakan kombinasi yang tersedia:

* perceptual hash
* image similarity
* embedding similarity jika sudah ada
* prompt diversity validation
* metadata comparison

Jangan hanya membandingkan checksum karena gambar yang hampir sama akan memiliki checksum berbeda.

Threshold harus configurable.

Contoh:

```text
duplicate threshold >= 0.92 similarity
near-duplicate warning >= 0.85
```

Jika dua konsep terlalu mirip:

* tandai duplicate
* regenerate salah satu
* batasi retry
* simpan alasan
* jangan memasukkan duplicate ke final deliverable

Test harus membuktikan dua asset identik ditolak.

# 14. Image QC

Phase 1B menemukan `image_qc` sebelumnya stub.

Implementasikan real image QC untuk batch output.

QC minimal:

* image readable
* correct aspect ratio
* correct dimensions
* visual relevance to prompt
* no severe artifacts
* no obvious text corruption jika desain mengandung teks
* no blank output
* no duplicate
* project logo use sesuai policy
* composition quality
* brand consistency

Gunakan:

* deterministic technical checks
* vision model scoring bila provider tersedia
* configurable threshold

Contoh score:

```text
technical: 30
prompt relevance: 25
composition: 20
brand consistency: 15
text/readability: 10
```

Default pass threshold dapat 70, tetapi ambil dari config jika sudah tersedia.

Jangan menyebut QC berhasil jika hanya metadata check tanpa visual assessment.

# 15. Text rendering in social design

Jika image provider sering merusak teks, audit strategi.

Preferensi:

1. Generate visual background tanpa teks.
2. Overlay approved text menggunakan Sharp/SVG composition.
3. Gunakan font yang tersedia secara legal di environment.
4. Render logo dan CTA secara deterministik.
5. Validate text bounding box.

Jangan mengandalkan image model untuk menghasilkan teks panjang yang akurat.

Jangan menyertakan font file dalam deliverable tanpa lisensi.
