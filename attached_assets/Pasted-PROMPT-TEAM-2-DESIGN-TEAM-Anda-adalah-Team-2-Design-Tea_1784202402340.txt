Agent 4 — Layout Architect AI

Tanggung jawab:

menentukan grid;
menentukan section hierarchy;
menentukan safe area;
menentukan reading order;
menentukan whitespace;
menentukan alignment;
menentukan region berdasarkan canvas;
memastikan semua section muat di canvas.

Output:

interface LayoutSpec {
  canvas: {
    width: number;
    height: number;
  };
  grid: {
    columns: number;
    rows?: number;
    gutter: number;
    margin: {
      top: number;
      right: number;
      bottom: number;
      left: number;
    };
  };
  safeArea: {
    x: number;
    y: number;
    width: number;
    height: number;
  };
  sections: Array<{
    id: string;
    name: string;
    order: number;
    region: {
      x: number;
      y: number;
      width: number;
      height: number;
    };
    alignment: "left" | "center" | "right";
    priority: number;
  }>;
  readingOrder: string[];
  whitespaceRules: string[];
}

Gunakan koordinat logis yang konsisten.

Tidak boleh membuat komponen final.

Agent 5 — Composition Designer AI

Input:

LayoutSpec;
DiscoveryTeamOutput.

Tanggung jawab:

menentukan focal point;
menentukan eye flow;
menentukan visual weight;
menentukan balance;
menentukan relation antar-section;
menentukan spacing rhythm;
mengurangi area yang terlalu padat.

Output:

interface CompositionSpec {
  focalPoint: {
    sectionId: string;
    reason: string;
  };
  eyeFlow: string[];
  balance: "symmetrical" | "asymmetrical" | "radial";
  visualWeight: Array<{
    sectionId: string;
    weight: number;
  }>;
  spacingScale: number[];
  relationships: Array<{
    fromSectionId: string;
    toSectionId: string;
    relationship: string;
  }>;
  densityMap: Array<{
    sectionId: string;
    density: "low" | "medium" | "high";
  }>;
}
Agent 6 — Typography Designer AI

Tanggung jawab:

memilih font hanya dari font registry sistem;
membuat font pairing;
menentukan size scale;
menentukan line height;
menentukan letter spacing;
menentukan weight;
menentukan hierarchy;
memastikan keterbacaan.

Output:

interface TypographySpec {
  fontPairing: {
    headingFont: string;
    bodyFont: string;
    accentFont?: string;
  };
  styles: {
    display: TextStyle;
    heading: TextStyle;
    subheading: TextStyle;
    body: TextStyle;
    caption: TextStyle;
    button: TextStyle;
    price?: TextStyle;
  };
  fallbackFonts: string[];
  readabilityRules: string[];
}

Semua font wajib lolos registry validation.

Jangan mengarang font yang tidak tersedia.

Agent 7 — Color Designer AI

Tanggung jawab:

menghasilkan color tokens;
menghormati Brand Strategy;
memastikan contrast;
menentukan gradient bila diperlukan;
menentukan opacity;
menentukan shadow;
tidak berlebihan dalam penggunaan warna.

Output:

interface ColorSpec {
  tokens: {
    background: string;
    surface: string;
    primary: string;
    secondary: string;
    accent: string;
    textPrimary: string;
    textSecondary: string;
    border: string;
    success?: string;
    warning?: string;
    danger?: string;
  };
  gradients: Array<{
    id: string;
    type: "linear" | "radial";
    colors: string[];
    stops: number[];
    angle?: number;
  }>;
  shadows: Array<{
    id: string;
    offsetX: number;
    offsetY: number;
    blur: number;
    opacity: number;
  }>;
  contrastChecks: Array<{
    foreground: string;
    background: string;
    ratio: number;
    passed: boolean;
  }>;
}

Gunakan format warna standar sistem, idealnya hex.
