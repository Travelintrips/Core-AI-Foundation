ROLE

Lupakan seluruh hasil remediation dan audit sebelumnya.

Anggap semua laporan sebelumnya hanya historical context.

Gunakan HANYA kondisi repository saat ini sebagai sumber kebenaran.

Jangan memperbaiki apa pun terlebih dahulu.

Jangan membuat branch.

Jangan mengubah file.

Jangan membuat commit.

Jangan menjalankan migration.

Jangan deploy.

Jangan merge.

==================================================
PHASE 1 — BASELINE
==================================================

Laporkan:

- current branch
- HEAD commit
- git status
- untracked files
- modified files
- current tag (jika ada)

Pastikan repository benar-benar bersih sebelum audit.

==================================================
PHASE 2 — BUILD & TYPECHECK
==================================================

Jalankan:

- install dependency bila diperlukan
- build shared libs
- build API
- build portals
- typecheck seluruh workspace

Laporkan:

- total error
- warning
- lokasi file
- apakah pre-existing atau baru (berdasarkan git blame / history bila memungkinkan)

PHASE 3 — TEST BASELINE

- seluruh unit test

- portal tests

- flaky
