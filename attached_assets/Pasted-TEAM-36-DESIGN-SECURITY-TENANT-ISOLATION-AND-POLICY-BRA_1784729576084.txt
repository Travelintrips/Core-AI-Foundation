==================================================

- cross-tenant read;
- cross-tenant write;
- IDOR;
- platform scope misuse;
- actor spoofing;
- tenantId injection;
- unsafe plugin contribution;
- arbitrary module loading;
- prompt injection through artifact metadata;
- unsafe HTML/SVG;
- signed URL leakage;
- expired token reuse;
- duplicate execution;
- cost abuse;
- oversized upload;
- resource exhaustion;
- raw provider payload exposure;
- public review token brute force;
- audit trail gaps.

==================================================
TENANT ISOLATION
==================================================

Verifikasi:

- tenant ID berasal dari RequestContext;
- repository selalu menerima context;
- query selalu scoped;
- update/delete memakai tenant scope;
- event/cost/job/artifact tidak dapat cross-tenant;
- platform scope explicit;
- tenant null fail-closed;
- public token tidak menjadi tenant authority.

==================================================
PLUGIN SECURITY
==================================================

Plugin contribution harus:

- static/compiled;
- manifest validated;
- contract version checked;
- known registry;
- no remote JavaScript;
- no arbitrary import path;
- no arbitrary SQL;
- no raw secret;
- limited capability;
- permission-aware.

==================================================
AI SECURITY
==================================================

Verifikasi:

- prompt context sanitized;
- system instruction tidak dapat diubah oleh artifact metadata;
- provider key dari secret service;
- output validated;
- cost/budget guard;
- no raw chain-of-thought;
- no arbitrary tool execution;
- no direct provider call dari frontend/plugin.
