TEAM 14 — UNIVERSAL ASSET BROWSER AND LIBRARY

BRANCH WAJIB:
feature/team-14-asset-browser

==================================================
TUJUAN
==================================================

Bangun Asset Browser reusable untuk menemukan, memilih, mengunggah, dan
menghubungkan asset ke project design.

Asset mencakup:

- image;
- document;
- PDF;
- video preview;
- font reference;
- material preview;
- icon;
- logo;
- reference;
- generated artifact;
- external approved asset.

Jangan membuat storage service kedua.

==================================================
AUDIT
==================================================

Audit:

- upload components;
- asset tables/API;
- signed URLs;
- Supabase/storage utilities;
- image galleries;
- search/filter;
- pagination;
- file validation;
- malware/security patterns;
- asset permissions;
- existing Creative AI asset UI.

==================================================
SOURCE REGISTRY
==================================================

Asset source dapat berasal dari:

- project assets;
- brand library;
- generated artifacts;
- uploaded references;
- shared approved library;
- plugin-contributed source.

Jangan membuat arbitrary external URL source.

Source registry harus deterministic dan permission-aware.

==================================================
UPLOAD
==================================================

Gunakan API/upload service existing.

Validasi:

- MIME;
- extension;
- size;
- filename;
- duplicate;
- unsupported format;
- upload failure;
- canceled upload.

Jangan menyimpan base64 besar dalam state.

Jangan menerima SVG mentah untuk injection.

==================================================
SECURITY
==================================================

- signed/authenticated URL;
- no secret path;
- no raw storage bucket exposure bila tidak diperlukan;
- tenant authority dari backend;
- sanitize filename;
- safe media rendering;
- revoke object URL;
- no arbitrary HTML preview;
- permission check per asset;
- no cross-tenant selection.
