TEAM 18 — UNIVERSAL ANNOTATION AND COMMENT SYSTEM

BRANCH WAJIB:
feature/team-18-annotation-system

==================================================
TUJUAN
==================================================

Bangun annotation system universal untuk artifact review.

Annotation dapat berupa:

- point pin;
- rectangle;
- region reference;
- free-text comment;
- reply;
- status;
- assignee;
- priority;
- version anchoring;
- frame/page anchoring.

Freehand drawing kompleks bukan scope V1.

==================================================
CONTRACT
==================================================

Minimal:

Annotation
AnnotationAnchor
AnnotationGeometry
AnnotationThread
AnnotationComment
AnnotationStatus
AnnotationPriority
AnnotationPermission
AnnotationMutation
AnnotationSelection

Anchor harus dapat menunjuk:

- artifact;
- version;
- frame/page/view;
- normalized coordinates;
- renderer element/region opaque ID.

Gunakan normalized coordinates, bukan hanya pixel absolut.

==================================================
ANNOTATION STATES
==================================================

Minimal:

- open;
- acknowledged;
- resolved;
- reopened;
- archived.

Jangan mengganti client review status.

Annotation status terpisah dari review decision.

==================================================
THREAD
==================================================

Dukung:

- comment;
- reply;
- edit own comment bila diizinkan;
- resolve;
- reopen;
- assign;
- mention boundary bila existing system mendukung;
- timestamps;
- actor;
- deleted/redacted state.

Jangan membuat rich-text editor besar.

==================================================
WORKSPACE INTEGRATION
==================================================

Team 11:

- gunakan CanvasOverlayHost;
- jangan membuat canvas kedua.

Team 13:

- annotation dapat muncul sebagai optional virtual layer.

Team 15:

- annotation melekat pada version yang benar.

Team 16:

- annotation summary dapat digunakan saat review.

Jika dependency belum tersedia, gunakan adapter lokal sempit.

==================================================
GEOMETRY
==================================================

Pure utilities:

- normalizePoint;
- denormalizePoint;
- clampAnchor;
- transformAnchor;
- validateGeometry;
- calculateAnnotationBounds;
- migrateAnchorBetweenViewportSizes;
- detectOutsideContent.

==================================================
SECURITY
==================================================

- sanitize comment;
- no raw HTML;
- permissions;
- tenant isolation;
- no cross-project anchor;
- actor identity dari backend;
- no client-authoritative createdBy;
- rate-limit reuse bila public review;
- no token exposure.

==================================================
ACCESSIBILITY
==================================================

- annotation pin focusable;
- accessible label;
- keyboard select;
- comment thread navigation;
- resolve/reopen announced;
- not color-only;
- screen-reader summary list.
