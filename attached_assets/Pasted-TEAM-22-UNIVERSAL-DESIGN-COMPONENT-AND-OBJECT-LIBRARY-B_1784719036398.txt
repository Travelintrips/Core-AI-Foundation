TEAM 22 — UNIVERSAL DESIGN COMPONENT AND OBJECT LIBRARY

BRANCH WAJIB:
feature/team-22-component-library

==================================================
TUJUAN
==================================================

Bangun library universal untuk reusable design components dan objects.

Contoh:

- garment part reference;
- furniture object;
- architectural component;
- packaging element;
- branding element;
- product component;
- jewelry component;
- landscape object.

Core harus domain-neutral.

==================================================
SCOPE
==================================================

Bangun:

ComponentDefinition
ComponentCategory
ComponentVariant
ComponentParameterSchema
ComponentAssetReference
ComponentCompatibility
ComponentPlacementCapability
ComponentSource
ComponentStatus
ComponentRegistry
ComponentBrowser
ComponentPicker
ComponentInstantiationRequest

==================================================
PRINSIP
==================================================

Component library menyimpan definisi reusable.

Instance component dalam artifact adalah tanggung jawab renderer/plugin/workspace.

Jangan membuat scene graph atau CAD engine kedua.

==================================================
REGISTRY
==================================================

Registry harus:

- unique component ID;
- version-aware;
- variant-aware;
- plugin ownership;
- category;
- domain compatibility;
- required capabilities;
- dependency;
- deprecation;
- deterministic resolution.

==================================================
PARAMETER SCHEMA
==================================================

Dukung:

- dimensions;
- enum;
- color;
- material reference;
- number;
- boolean;
- asset reference;
- text;
- custom plugin schema reference.

Jangan mengeksekusi arbitrary code dari schema.

==================================================
BROWSER
==================================================

Dukung:

- search;

- compatible domain;
- tag;
- variant;
- preview;
- selected state;
- unavailable/deprecated;
- permission;
- empty/loading/error.

==================================================
INSTANTIATION
==================================================

Expose request contract:

- componentId;
- version;
- variantId;
- targetArtifactId;
- parentElementId optional;
- parameters;
- transform;
- requestedBy;
- idempotencyKey.

Jangan membuat persistence implementation jika belum ada canonical service.
