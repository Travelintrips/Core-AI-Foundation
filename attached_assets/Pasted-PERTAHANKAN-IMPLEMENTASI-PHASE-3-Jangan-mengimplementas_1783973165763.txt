12. AUDIT UNKNOWN INDUSTRY SEMANTICS

Laporan menyebut:

Developer properti perumahan

berhasil cocok ke profile Property, tetapi UI tetap menampilkan badge:

Industri belum spesifik

Periksa semantics usedFallbackIndustry.

Bedakan:

exact profile match
alias profile match
generic fallback

Gunakan model seperti:

matchType: "exact" | "alias" | "generic-fallback"

UI warning “Industri belum spesifik” hanya boleh tampil pada:

generic-fallback

Alias yang berhasil mengarah ke profile spesifik tidak seharusnya dianggap generic fallback.

Contoh:

developer properti → Property
arang/briket → Charcoal
kopi/kedai kopi → Coffee Shop

Semua ini harus dianggap matched profile, walaupun melalui alias.

13. AUDIT EXPORT IMPORT PROFILE RESOLUTION

Laporan menyebut input:

Ekspor impor / logistik

cocok ke profile Logistics, bukan Export Import.

Tentukan aturan yang lebih tepat dan deterministik.

Untuk multi-keyword:

gunakan exact phrase priority;
gunakan alias specificity;
jangan hanya memilih keyword pertama secara kebetulan.

Contoh expected:

"export import" → export-import
"ekspor impor" → export-import
"logistics" → logistics
"freight forwarding" → freight-forwarding
"ekspor impor dan logistik" → profile paling spesifik atau combined rule yang terdokumentasi

Jangan membuat fuzzy matcher kompleks.

Gunakan ordered alias registry dengan specificity score bila perlu.

Tambahkan tests.
