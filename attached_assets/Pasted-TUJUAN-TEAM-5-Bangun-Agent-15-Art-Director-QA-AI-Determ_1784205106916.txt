DETERMINISTIC QA GATE

Buat file:

artifacts/api-server/src/services/design-ai/orchestrator/qaGate.ts

Jangan bergantung sepenuhnya kepada keputusan AI.

Final publish decision harus dihitung oleh deterministic gate.

Gunakan default rule:

const publishReady =
  qaReport.overallScore >= 90 &&
  qaReport.readyToPublish === true &&
  engineering.finalValidation.passed === true &&
  engineering.finalValidation.errors.length === 0 &&
  qaReport.blockingIssues.length === 0;

Tambahkan aturan:

Jika finalValidation.passed = false
→ tidak boleh publish.

Jika finalValidation.errors.length > 0
→ tidak boleh publish.

Jika QA menghasilkan readyToPublish=true tetapi score <90
→ tidak boleh publish.

Jika overallScore >=90 tetapi ada blockingIssues
→ tidak boleh publish.

Jika ada element out-of-bounds blocking
→ tidak boleh publish.

Jika ada missing variable binding
→ tidak boleh publish.

Jika CTA tertutup
→ tidak boleh publish.

AI tidak boleh override deterministic gate.

REVISION LOOP

Buat:

artifacts/api-server/src/services/design-ai/orchestrator/revisionLoop.ts

Maksimal:

const MAX_REVISION_CYCLES = 2;

Flow:

QA gagal
→ Revision Router
→ Jalankan kembali agent yang relevan
→ Jalankan ulang agent downstream yang terpengaruh
→ Jalankan Engineering Pipeline kembali
→ Jalankan QA kembali

Contoh dependency rerun:

Jika Layout Architect direvisi:
Layout
→ Composition
→ Typography
→ Color
→ Decoration
→ Components
→ Engineering
→ QA

Jika Typography Designer direvisi:
Typography
→ Component mapping bila diperlukan
→ Engineering
→ QA

Jika Color Designer direvisi:
Color
→ Decoration
→ Engineering
→ QA

Jika Component Builder direvisi:
Component Builder
→ Variable Designer
→ Asset Planner
→ Engineering
→ QA

Jika JSON Architect direvisi:
Engineering Pipeline
→ QA

Jika Optimizer direvisi:
Optimizer
→ Validator
→ QA

Jangan menjalankan seluruh pipeline dari awal jika tidak diperlukan.

Namun utamakan correctness dibanding optimasi premature.

Setelah dua revisi gagal:

status = "needs_human_review";

Sertakan seluruh report.

Jangan membuat infinite loop.
