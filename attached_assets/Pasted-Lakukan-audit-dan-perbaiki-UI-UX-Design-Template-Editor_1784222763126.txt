Lakukan audit dan perbaiki UI/UX Design Template Editor.

MASALAH SAAT INI

Banyak tulisan hampir tidak terlihat karena warna font terlalu terang (putih/light gray) di atas background putih.

Contohnya:

- Judul template di kiri atas hampir hilang.
- Version text hampir tidak terbaca.
- Toolbar (Add, Undo, Redo, Zoom) sangat pucat.
- Panel Layers terlalu pudar.
- Panel Properties terlalu pudar.
- Placeholder text hampir tidak terlihat.
- Semua typography terlihat seperti opacity terlalu rendah.

Target:

UI harus terlihat seperti Canva, Figma, atau Adobe Express:
- Bersih
- Kontras tinggi
- Mudah dibaca
- Modern
- Konsisten

====================================================

LAKUKAN AUDIT

Cari apakah ada:

- opacity-40
- opacity-50
- opacity-60
- text-white
- text-gray-200
- text-gray-300
- text-slate-300
- text-muted
- text-muted-foreground
- disabled style yang tidak tepat
- CSS global yang mengurangi opacity parent
- pointer-events / disabled state yang membuat seluruh toolbar menjadi pudar
