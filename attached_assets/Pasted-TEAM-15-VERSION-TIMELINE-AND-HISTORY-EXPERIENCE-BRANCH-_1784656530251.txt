TEAM 15 — VERSION TIMELINE AND HISTORY EXPERIENCE

BRANCH WAJIB:
feature/team-15-version-timeline

==================================================
TUJUAN
==================================================

Bangun UI version timeline untuk project dan artifact.

Team 15 tidak membuat version persistence baru.

Gunakan Team 09 version history contract jika tersedia atau adapter sempit jika
belum tersedia.

==================================================
FEATURE
==================================================

Dukung:

- daftar version;
- chronological timeline;
- created by;
- source;
- timestamp;
- change summary;
- status;
- active/current version;
- select historical version;
- compare entry point;
- restore request entry point;
- branch/variation visualization bila contract mendukung;
- loading/empty/error;
- pagination;
- deleted/unavailable version;
- retention/deprecation label.

==================================================
CONTRACT
==================================================

Minimal UI adapter:

VersionTimelineEntry
VersionSource
VersionActor
VersionChangeSummary
VersionSelection
VersionComparisonRequest
VersionRestoreRequest
VersionAvailability

Jangan mengubah canonical version contract.

==================================================
RESTORE
==================================================

Restore harus:

- permission-aware;
- confirmation;
- tidak langsung overwrite tanpa server response;
- memakai optimistic concurrency;
- menciptakan version baru bila canonical behavior demikian;
- menampilkan conflict;
- tidak menyatakan berhasil sebelum response sukses.

==================================================
COMPARE
==================================================

Team 15 hanya menyediakan:

- selection dua version;
- compare action;
- metadata comparison;
- integration boundary visual diff.

Pixel/vector/document diff engine bukan scope.
