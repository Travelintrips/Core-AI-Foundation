BAGIAN 4 — SCHEDULER RUNTIME
============================

Tambahkan runtime polling seperti Dispatcher.

Config:

* AI_SCHEDULER_ENABLED
* AI_SCHEDULER_POLL_INTERVAL_MS
* AI_SCHEDULER_TIMEZONE

Default:

* dev boleh auto-start
* production default false jika env tidak diset

Pastikan:

* scheduler tidak double-start
* tick concurrency-safe
* graceful shutdown
* error satu schedule tidak mematikan scheduler

====================================================================
BAGIAN 5 — TARGET TYPES
=======================

Schedule harus bisa membuat:

1. Job
   target_type = create_job

2. Event
   target_type = publish_event

3. Webhook placeholder
   target_type = webhook

4. Audit only
   target_type = audit_log

Untuk webhook placeholder cukup audit log dulu.

====================================================================
BAGIAN 7 — SLA / DEADLINE REMINDER
==================================

Tambahkan schedule type deadline_reminder.

Contoh:

* client review link belum dibuka setelah 24 jam
* project belum approve setelah 3 hari
* job failed lebih dari 1 jam

Untuk sekarang cukup buat framework dan contoh schedule.
