TUJUAN:

Menyelesaikan finding audit yang tersisa agar branch siap diaudit ulang dan diintegrasikan.

ATURAN KERJA WAJIB:

Untuk setiap branch:

1. Jalankan:
   git fetch origin --prune
   git switch <nama-branch>
   git pull --ff-only origin <nama-branch>
   git branch --show-current
   git status

2. Pastikan working tree bersih sebelum bekerja.

3. Baca implementation dan test existing.

4. Perbaiki hanya finding audit. Jangan menambah fitur baru.

5. Jalankan test dan typecheck yang relevan.

6. Commit dan push ke branch yang sedang aktif.

7. Pastikan:
   git status
   menunjukkan working tree clean.

8. Baru setelah itu pindah ke branch berikutnya.

JANGAN membuat branch batch baru.
JANGAN mencampur perubahan beberapa team dalam satu commit.
JANGAN merge ke main atau integration branch.

TEAM 12 — LAYOUT COMPOSER
==================================================

Tambahkan:

- maximum constraints
- maximum iterations
- maximum nesting depth
- solver timeout
- deadline check atau cancellation

- tidak boleh menyimpan partial output setelah timeout

==================================================
TEAM 13 — DYNAMIC COMPOSER
==================================================

Tambahkan terminal-state guard:

- completed tidak diproses ulang
- cancelled tidak diproses
- failed hanya melalui explicit retry
- processing tidak boleh diklaim dua worker
- duplicate idempotency key tidak membuat job baru

State transition harus atomic menggunakan transaction, conditional update,
optimistic lock, atau compare-and-set.
