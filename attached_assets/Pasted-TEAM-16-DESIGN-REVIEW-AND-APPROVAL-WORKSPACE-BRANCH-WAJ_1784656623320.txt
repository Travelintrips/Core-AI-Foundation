TEAM 16 — DESIGN REVIEW AND APPROVAL WORKSPACE

BRANCH WAJIB:
feature/team-16-review-workspace

==================================================
TUJUAN
==================================================

Bangun review workspace universal untuk:

- internal review;
- client review;
- approve;
- reject;
- request revision;
- review summary;
- reviewer status;
- decision history;
- due date;
- version-specific review.

Gunakan sistem client review existing.

Jangan membuat review database atau token system kedua.

==================================================
AUDIT
==================================================

Audit:

- creative_ai_client_reviews;
- comments;
- public review route;
- admin review UI;
- approve/reject/revision API;
- token/rate limiting;
- review statuses;
- project events;
- artifact versions;
- permissions.

==================================================
FEATURE
==================================================

Bangun reusable:

ReviewPermissionState

Dukung:

- pending;

- rejected;
- revision_requested;
- expired;
- canceled;
- superseded.

Gunakan status mapping existing. Jangan mengganti canonical statuses.

==================================================
DECISION
==================================================

Action:

- approve;
- reject;
- request revision;
- cancel decision bila diizinkan;
- acknowledge review;
- internal sign-off.

Setiap decision harus:

- permission-aware;
- version-aware;
- idempotent;
- require reason bila policy meminta;
- confirmation untuk irreversible action;
- menangani stale version;
- tidak double-submit;
- menampilkan audit result.

==================================================
CHECKLIST
==================================================

Checklist bersifat schema/config driven.

Dapat berasal dari:

- core;
- workflow;
- plugin;
- service policy.

Jangan hard-code checklist domain dalam core.

==================================================
PUBLIC REVIEW
==================================================

Pertahankan keamanan token existing:

- hash-first validation;
- rate limit;
- expiry;
- invalid token;
- revoked token;
- tenant boundary;
- no admin data leakage.

Jangan mengubah public review flow tanpa compatibility test.
