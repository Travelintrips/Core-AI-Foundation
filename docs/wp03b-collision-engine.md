# WP-03B — Collision Engine Design Contract

## Status: IMPLEMENTED

---

## 1. Coordinate system

- 2D top-down
- Origin: top-left of room boundary
- X axis: left → right (positive)
- Y axis: top → bottom (positive)

## 2. Units

- All distances in **centimetres (cm)**
- All angles in **degrees**

## 3. Rectangle anchor semantics

- `xCm`, `yCm` is the position of the **top-left corner** of the un-rotated bounding box (anchor = 0,0 by default)
- Rotation is applied around the **geometric center** of the bounding box
- Center = `(xCm + widthCm/2, yCm + depthCm/2)`

## 4. Rotation convention

- Degrees, clockwise from north (0° = facing up/north)
- Normalised to `[0, 360)` before any geometric operation
- Applied as a 2D rotation matrix around the bounding-box center

## 5. Edge-touch policy

- Two placements that share only a boundary edge (no interior overlap) are **NOT** a physical collision
- The SAT comparison uses `> COLLISION_EPSILON`, not `>= 0`
- Touching corners also count as non-colliding

## 6. Epsilon policy

- Centralised constant: `COLLISION_EPSILON = 1e-6` (in cm² overlap depth)
- Used in all SAT interval overlap comparisons
- Prevents false positives from floating-point rounding
- Never hardcoded inline — always imported from `types.ts`

## 7. Broad-phase algorithm

- **AABB (Axis-Aligned Bounding Box)**
- Generated by computing all 4 rotated corners and taking min/max of X and Y
- If two AABBs do not overlap (with epsilon), SAT is skipped
- Complexity: O(n) per placement, O(n²) pairs total (but most rejected at broad phase)

## 8. Narrow-phase algorithm

- **OBB (Oriented Bounding Box) using SAT (Separating Axis Theorem)**
- 4 candidate axes per rectangle pair (2 from each OBB's face normals, deduplicated for rectangles)
- If any axis separates the projections, the pair does NOT collide
- Overlap depth = minimum penetration depth across all axes
- Minimum translation axis tracked where practical

## 9. Clearance model

- Clearance zones are **expanded OBBs** around the placement
- `clearanceFrontCm`, `clearanceSideCm`, `clearanceBackCm` define per-side expansions
- Clearance OBB tested against other placement OBBs and room boundary
- Physical collision and clearance warning are **strictly separate** in the result

```json
{
  "physicalCollision": false,
  "clearanceWarnings": [
    { "type": "CLEARANCE_OVERLAP", "placementA": "...", "placementB": "...", "side": "front" }
  ]
}
```

## 10. Room-boundary policy

- Rectangular room boundary (widthCm × depthCm from the session)
- Each rotated corner of a placement is tested against [0, widthCm] × [0, depthCm]
- Violations classified as:
  - `PLACEMENT_OUTSIDE_ROOM` — one or more corners outside
  - `PLACEMENT_DIMENSIONS_INVALID` — zero or negative dimensions
  - `PLACEMENT_GEOMETRY_INVALID` — NaN, Infinity, or other invalid input
- Corners exactly on the boundary are **not** a violation (edge-touch policy)
- Do NOT silently clamp placement coordinates

## 11. Deterministic ordering

- Collision pair `(A, B)` always ordered by UUID lexicographic order: `A.id < B.id`
- Prevents duplicate pairs `(A,B)` and `(B,A)` from both appearing
- Self-pairs `(A,A)` are always excluded
- Archived placements (`isArchived = true`) excluded from all checks

## 12. Error codes

| Code | HTTP | Meaning |
|---|---|---|
| `SESSION_NOT_FOUND` | 404 | Session does not exist or belongs to another tenant |
| `PLACEMENT_NOT_FOUND` | 404 | Placement does not exist in session |
| `PLACEMENT_OUTSIDE_ROOM` | 422 | Placement corner(s) outside room boundary |
| `PLACEMENT_DIMENSIONS_INVALID` | 400 | Width or depth ≤ 0 |
| `PLACEMENT_GEOMETRY_INVALID` | 400 | NaN, Infinity, or other invalid input |
| `TENANT_REQUIRED` | 401 | No tenant context in request |
| `INTERNAL_ERROR` | 500 | Unexpected server error |

## 13. Performance constraints

- Placements loaded **once per session** (not per pair)
- Broad phase (AABB) MUST run before narrow phase (SAT)
- SAT not performed on pairs whose AABBs don't overlap
- Expected complexity: O(n²) pairs, O(1) per pair geometry check
- No spatial hashing unless measured performance requires it
- Stress test: 50-placement session must complete in < 50ms
